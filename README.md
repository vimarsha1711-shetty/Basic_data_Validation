# Basic Data Validation

## Objective
To improve data quality using dropdowns and validation rules in Excel.

## Tools Used
- Microsoft Excel

## Work Completed
- Created a sample employee dataset.
- Added Gender and Department dropdowns.
- Applied Age validation (18–60).
- Applied Salary validation (₹10,000–₹1,00,000).
- Applied Joining Date validation (01-01-2020 to 31-12-2026).
- Tested the validation rules.

## Result
The Excel sheet helps prevent invalid data entry and improves data consistency.
